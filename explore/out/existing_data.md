Post hoc; not part of the frozen plan. Generated by `explore/analyse_existing.py` from `results/full_scored.jsonl`, `runs/full/`, `runs/calib/` and the item files. See `PROTOCOL.md` entry 36.

## 1. How the line-final tone is chosen

Modern tones (pypinyin). The rule asks a second line (forward) to end on 平 and a first line (reverse) on 仄. On the unseen set the given line always ends the conventional way (93% of items keep both rules), so direction and the given line's tone always point the same way there. The recall set separates them: its classical originals often break the convention, so a given first line may end on 平 and a given second line on 仄.

### Rule or imitation? Recall set, both conditions

Share of answers ending on 平 in each cell; then the two effects with 95% bootstrap intervals over items. *Rule effect* = how much more often the line ends on 平 when the rule asks for 平 (forward) than when it asks for 仄 (reverse), holding the given line's tone fixed: +100 for a perfect rule follower, 0 for a model blind to the rule. *Imitation effect* = how much more often the line ends on 平 when the given line ends on 平, holding direction fixed: positive means copying the given tone, negative means contrasting with it.
