# Diffusion Fiction Lab

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.24448804.svg)](https://doi.org/10.5281/zenodo.24448804)

This project studies whether diffusion language models write better Chinese chapter-heading couplets (回目) than a similarly sized autoregressive model.

See the [study protocol](PROTOCOL.md) and [third-party notices](NOTICE.md).
